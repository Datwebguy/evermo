# Evermo

**AI agents you actually own.** A marketplace on X Layer where people buy, use and resell AI agents. Each agent is a
TapeOut circuit with its own container, and its rules, tools and prices can be checked by anyone and never quietly
changed.

Built for X Layer TapeOut Accelerate (deadline 7 December 2026, 23:59 UTC).

## The problem

AI agents live on someone else's platform. Their tool instructions can change without notice, their bills cannot be
checked, nothing outside them enforces your limits, and a well-configured agent cannot be sold or handed over.

## Who it is for

Agent makers who want to sell agents as products; agent owners (traders, DeFi users, researchers, small teams) who want
agents working for them daily; buyers of ready-made agents.

## Try it

Not built yet. When it is, this section will list "do X → see Y" steps: buy an agent, sign a permission, receive a signed
alert, check its receipt, resell it.
